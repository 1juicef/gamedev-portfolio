  <action>
Create `src/components/LazyVideoThumbnail.vue` following the RESEARCH Pattern 1 skeleton, which is already written in this project's Options API + `Vue.extend()` + TypeScript style. Props: `src` and `poster`, both `{ type: String, required: true }`. Data: `hasIntersected` (starts false) and `observer` (IntersectionObserver | null). In `mounted()`, if `IntersectionObserver` is undefined, set `hasIntersected = true` and return (graceful fallback); otherwise create an observer with `rootMargin: "200px 0px"` that on intersect sets `hasIntersected = true` and, in `$nextTick`, calls the video element's `.play()` with a `.catch(() => {})` (autoplay promise can reject), and on leaving the viewport calls `.pause()`. Disconnect the observer in `beforeDestroy()`.

Template: a root `<div ref="wrap" class="lazy-video-thumb">` containing a `<video v-if="hasIntersected" ref="video" :poster="poster" preload="none" muted loop playsinline>` with a `<source :src="src" type="video/mp4" />`, and a fallback `<img v-else :src="poster" loading="lazy" class="lazy-video-thumb-poster" alt="" />`. The `muted loop playsinline` attributes and `preload="none"` satisfy D-04 (autoplay muted, loop, in-viewport only) and D-05 (poster shown while the video file loads). The `loading="lazy"` on the poster `<img>` must be placed before `:src` in attribute order.

Use `<style scoped>` (project convention). Relocate the aspect-ratio/box technique from GameProjects.vue's `.project-image-wrap-video` into this component's scoped styles: media fills width 100% with `height: auto` and a `1px solid rgba(255,255,255,0.14)` border to match the existing `.project-image` framing. Do not force a fixed 16:9 ratio (the GIF-sourced clips are not all 16:9 — let the video/poster keep their intrinsic ratio to avoid letterboxing).
  </action>
