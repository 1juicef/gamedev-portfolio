  <name>Task 1: Autoplay, mute, and loop the Other Stuff gallery videos</name>
  <files>src/views/OtherStuff.vue</files>
  <read_first>src/components/LazyVideoThumbnail.vue — this is the reference implementation. Read it in full before editing; the goal is to mirror its attribute set and its mounted() fallback, adapted for multiple elements.</read_first>
  <action>
In `src/views/OtherStuff.vue`, bring the `&lt;video&gt;` element inside the `v-for` (currently lines 18-27) in line with the pattern already proven in `LazyVideoThumbnail.vue`.

Template changes on that `&lt;video&gt;` element:
- Delete the bare boolean attribute currently on line 21 that makes the browser draw its native playback UI over the clip. These gallery items are ambient background art, not a player.
- Add, one attribute per line, matching this file's existing 2-space-per-level indentation: `autoplay`, `muted`, `loop`, `playsinline`.
- Keep `preload="metadata"` and `:aria-label="item.alt"` exactly as they are, and keep the `&lt;source&gt;` child plus the no-support fallback text.
- Add `ref="video"` so the script can reach the elements.
- Leave the `&lt;img&gt;` branch, the `v-if`/`v-else` structure, and the `:key`/`:style` bindings on the wrapping cell untouched.

Script changes inside the `Vue.extend({ ... })` options object:
- Add a `mounted` option after `data`, written as `mounted: function () { ... }` to match the style used in `LazyVideoThumbnail.vue` and the `data: function ()` already in this file.
- Critical difference from the reference: because `ref` is used inside a `v-for`, Vue 2 populates `this.$refs.video` as an **array** of elements, not a single element. Cast it to `HTMLVideoElement[] | undefined` (the project runs TypeScript in strict mode), guard the undefined/empty case, then iterate and call `.play()` on each element, attaching `.catch(() => {})` to every call.
- A rejected play promise means the browser refused autoplay. That is an expected outcome under browser autoplay policy, not an error — swallow it silently, exactly as the reference does. Do not log, do not rethrow, do not surface UI.
- Add a short comment explaining why the imperative play() call exists alongside the declarative attribute, mirroring the reasoning already written in `LazyVideoThumbnail.vue`.
- Unlike the reference, these elements have no `poster`, so there is no static fallback frame when autoplay is refused. Do not invent one — the first decoded frame is acceptable.

Do not touch the `media` data array, the `&lt;style scoped&gt;` block, or any other file.
  </action>
