- **Indentation in `.vue` and `src/router/index.ts` is 2 spaces**, not 4 (`Header.vue`, `Contact.vue`, `App.vue`, `router/index.ts` all use 2). The 4-space convention noted in `.claude/CLAUDE.md` applies to the HTML strings inside `src/data/*.ts`, not to SFCs. Match the neighbouring files: 2 spaces.
- Asset paths are root-relative with **no leading slash**: `img/other-stuff/...` (matches `img/projects/...` usage in `Resume.vue` and `GameProjectsData.ts`).

  `<video class="..." controls preload="metadata">` wrapping `<source src="..." type="video/mp4" />` plus a plain-text fallback line.
- Colors come from `src/css/variables.less` via `@import '../css/variables.less';` inside the scoped style block (see `Header.vue`). Available: `@bodyBgColor`, `@contentBgColor`, `@textColor`, `@accentColor`.

- Components are `Vue.extend({ name: "...", data: function () { ... } })` with `<style scoped lang="less">`.
